# ADCE Archived & Historical Documentation

> **Archive Status:** Deprecated / Non-Normative Historical Storage
> **Epistemic Authority:** Tier 6 (Quarantined Artifacts)
> **Agent Navigation Instruction:** Do not index or cite files within `docs/archive/` during active architecture planning or implementation tasks. All active contracts are maintained in `docs/CONTEXT.md` and `docs/architecture/`.

## Purpose of this Archive

This directory stores superseded specifications, empirical spike ledgers, podcast transcripts, and automated test run outputs generated during earlier developmental milestones. These artifacts are retained for historical auditability and retrospective reference, but they do not represent current architectural commitments or test standards.

## Quarantined Categories

| Subdirectory | Contents & Retrospective Context |
| :--- | :--- |
| `audiobooks/` | Audio scripts and binary documents (`.docx`, `.pdf`) covering early Win32 and UIA investigations. |
| `external_research/` | Upstream exploratory surveys of external accessibility libraries (AccessKit, TirgDll, TreeSitter) conducted prior to selecting the `FlaUI.UIA3` stack. |
| `deprecated_specs/` | Exhaustive specifications for the legacy Claim Verification Matrix and custom stimulus drivers superseded by standard xUnit testing. |
| `audit_artifacts/` | Interim working notes from early audit stages prior to full codebase consolidation. |
